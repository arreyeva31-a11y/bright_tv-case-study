BRIGHTTV DATA ANALYSIS PROJECT;

PROJECT OVERVIEW
This project analyses BrightTv user profiles and viewing behavior to provide Insights that can help grow the subscription base.

OBJECTIVES
_ Understand user and viewing trends
_ Identify factors influencing content consumption
_ Analyse subscriber behavior
_ Provide recommendations for customer growth

_ Dtabricks
_ GitHub
_ Miro
_ Lovable
_ Data studio

PROJECT FILES
_ DATA; Dataset files
_ SQL; Analysis Queries
_ Excel; Pivot tables
_ Power BI; Dashboard

 KEY INSIGHTS
 _ Most popular channels

 _ Subscriber behavior and analysis
